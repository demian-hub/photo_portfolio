# Still photography — design direction

## References and decisions

Reference 1 contributes immersive photography and restrained navigation; reference 2 contributes generous section spacing and clear scale; reference 3 contributes quiet gallery composition and expressive serif typography. No reference artwork, logo, text or layout is reproduced. Stock images are marked as samples.

The UI/UX search returned a motion-heavy dark portfolio direction twice. That category matches portfolios, but heavy motion and a fully dark page conflict with this brief. Use its image-first hierarchy and accessibility guidance, while choosing a light gallery and minimal motion.

## Tokens

- Paper #FAF9F6: main background
- Ink #252A28: primary text and buttons
- Slate #646B66: secondary text
- Sage #53634E: functional accent and focus
- Line #D7DAD3: separators
- White #FFFFFF: text on dark surfaces
- Type: locally hosted Cormorant Garamond 400/500 for the English wordmark and display; locally hosted Noto Sans KR variable for Korean and UI.
- Scale: display 72–144px, section 48–72px, Korean subheading 24–36px, body 16px, captions 13–14px.

## Layout

Left-aligned, image-first composition; content max width 1440px with adaptive 24–80px gutters. Desktop photographs form two columns. The first two portraits share a calm consistent landscape frame; categories are filterable without horizontal scrolling. Mobile uses one column.

## Review before implementation

The memorable treatment is the oversized serif opening alongside the portrait. Remove unrelated decorative numbering, repeated eyebrows, gradients, generic cards and automated carousels. Keep gallery and forms quiet. A warm white follows the agreed brief; avoid terracotta accents and use muted sage only where useful. Do not invent a real photographer identity: Still is a provisional studio label. About text uses only the provided ten-year experience and clearly editable working-method copy.
