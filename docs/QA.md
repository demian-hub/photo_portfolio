# 제작 및 검수 결과

검수일: 2026-11-05 (Asia/Seoul)

## 구현

- 참고 이미지 3장의 사진 중심 구성, 큰 타이포와 여백을 분석하여 별도 디자인으로 구현
- 공개 6개 섹션, 5개 촬영 분야별 2장, 총 10장의 샘플 이미지
- 사진 필터와 원본 비율 확대, 키보드 Escape 닫기 및 포커스 복귀
- 문의 저장·접수번호 안내·입력 검증·반복 제출 제한
- SQLite 및 관리자 인증, 문의 목록·상세·검색·필터·상태 관리
- 모바일 고정 문의 버튼, 모바일 메뉴, 로컬 웹폰트와 이미지 최적화

## 실제 검증

- 프로덕션 빌드 성공
- 자동 테스트 3개 통과: 필드 검증, 비밀번호·출처·위조 세션, HTTP 통합 흐름
- HTTP 통합: 비로그인 조회/변경 차단, 다른 출처 요청 거부, 동의 누락 거부, 문의 DB 저장, 잘못된 로그인 거부, 로그인 쿠키 속성, 검색, 상태 변경, 필터, 로그아웃 이후 접근 차단, 반복 접수 제한
- 실제 브라우저에서 샘플 문의 제출 → 접수번호 #0001 표시 → 관리자 로그인 → 해당 문의 조회 → 상세 확인 → ‘상담 중’ 저장 → 검색 결과 없음 → 검색 및 상태 필터로 다시 조회 → 로그아웃 확인
- 문의는 검수용 이름·이메일로 생성했으며 검수 후 운영 DB에서 해당 테스트 레코드만 정리
- 375×812, 768×1024, 812×375, 1440×1000, 1920×1080 브라우저 화면 확인
- 위 너비에서 문서 가로 넘침 없음 확인; 모바일 1열·태블릿 2열 확인
- 모바일 메뉴 열기와 작업물 이동 확인
- 빈 폼 제출 시 항목별 오류 및 포커스 이동 확인
- 중복 ID 수정 후 중복 없음 확인
- 수정본 브라우저 콘솔의 error/warn 로그 없음 확인
- SQLite 온라인 백업 및 이미지 복사 실행 성공

## 수정한 문제

- Windows의 3000번 포트 바인딩 불가: 기본 포트를 4173으로 변경
- 연락처 입력 ID와 문의 섹션 ID 중복: 입력 ID를 inquiry-contact로 분리
- Next.js 내부 요청 URL 정규화와 브라우저 주소 차이: 명시적 SITE_URL 또는 요청 Host를 기준으로 출처 확인
- 인물 사진 썸네일의 크롭 위치 조정
- 공개 콘텐츠 전체를 main 랜드마크에 포함하고 바로가기 위치를 히어로에 지정

## 현재 운영 범위

로컬 주소는 http://127.0.0.1:4173 입니다. 관리자 로그인 정보는 Git에 포함되지 않는 .local/admin-access.txt에 있습니다.

현재 사진과 스튜디오명은 샘플입니다. 실제 작가명·활동 지역·연락처·SNS·사진과 개인정보 보관 정책을 공개 전 확정해야 합니다. 인터넷 외부 접속, HTTPS, 공유기/방화벽 변경, OS 자동 실행·절전 변경은 적용하지 않았습니다. 관련 실행 스크립트와 프록시 예시는 준비했습니다.

반응형 확인은 데스크톱 브라우저의 뷰포트 변경으로 수행했습니다. 실물 모바일 기기, 전체 WCAG 감사, 실제 외부 네트워크 공개 환경은 검증하지 않았습니다.
